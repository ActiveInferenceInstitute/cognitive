# Ant Colony Agents

This module implements agents capable of stigmergic coordination and collective problem solving using Active Inference principles.

## Agent Types

### Foraging Ant

- **Behavior**: Explores environment, deposits pheromones, and retrieves food.
- **Active Inference**: Minimizes free energy by reducing uncertainty about food locations.
