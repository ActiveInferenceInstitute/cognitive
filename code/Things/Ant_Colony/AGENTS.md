# Ant Colony agents

Documentation only; no runtime code lives in this folder and nothing can be
imported from it.

The concept is a foraging ant treated as an active inference agent: it explores,
deposits pheromone, and returns food, and its behavior is read as reducing
uncertainty about where food is. The design notes are in
[[code/Things/Ant_Colony/Ant_Colony_README|Ant_Colony_README]].
