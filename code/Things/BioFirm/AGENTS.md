# BioFirm Agents

The BioFirm agent represents an organization or a bioregional system modeled through Active Inference.

## Agent Architecture

### Organizational Agent

- **State Space**: Represents internal organizational states (e.g., resources, morale) and external market/ecological states.
- **Policy**: Actions taken to maintain homeostasis (viability) of the organization.
