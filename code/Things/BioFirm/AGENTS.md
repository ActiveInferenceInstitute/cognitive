# BioFirm agents

Documentation only; no runtime code lives in this folder and nothing can be
imported from it.

The concept is an organizational or bioregional agent. Its state space covers
internal states (such as resources) and external ones (market or ecological),
and its policy is the set of actions that keep the system viable. The state
spaces and schema are written up in
[[code/Things/BioFirm/BioFirm_README|BioFirm_README]] and
[[code/Things/BioFirm/docs/earth_systems_schema|the earth systems schema]].
