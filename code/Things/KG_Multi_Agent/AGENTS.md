# KG Multi-Agent Documentation

The KG Multi-Agent folder documents a conceptual multi-agent framework for
knowledge extraction, analysis, and visualization of AI-agent conversations.
The folder contains `README.md`, three concept notes (`Ant_Swarm.md`,
`KG_ActInf_Search.md`, `SWR_Swarm.md`), and a `MKG_Multi_Agent/` subfolder
with its own `README.md`.

## Notes

- `README.md` is the implementation overview; the sibling notes are concept
  studies.
- The folder does not ship importable runtime code at this level; do not
  import from it.
- Knowledge-base links are conceptual pointers, not runtime dependencies.
