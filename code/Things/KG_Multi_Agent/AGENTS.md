# KG Multi-Agent Documentation

The KG Multi-Agent folder documents design sketches for multi-agent systems that
work on a knowledge graph.
The folder contains `README.md`, three concept notes (`Ant_Swarm.md`,
`KG_ActInf_Search.md`, `SWR_Swarm.md`), and a `MKG_Multi_Agent/` subfolder
with its own `README.md`.

## Notes

- `README.md` is the overview; the sibling notes are concept studies.
- The folder, including `MKG_Multi_Agent/`, contains no code; do not import
  from it.
- Knowledge-base links are conceptual pointers, not runtime dependencies.
