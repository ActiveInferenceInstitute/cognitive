# Baseball Game Documentation

The Baseball Game folder is an archived concept study: it documents a
strategic, game-theoretic treatment of competitive decision-making rather
than shipping an executable implementation. The folder contains `README.md`
and `Baseball_Game.md` only.

## Notes

- See `README.md` for the folder overview and `Baseball_Game.md` for the
  concept notes.
- No runtime code lives in this folder; do not import from it.
- Links to the knowledge base (`decision_making`, game theory concepts) are
  conceptual pointers, not runtime dependencies.
