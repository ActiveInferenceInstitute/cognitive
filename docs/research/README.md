# Research documentation index

This directory contains research-oriented material: methods, applications,
and domain notes. It is conceptual documentation; claims must be grounded in
the repository or in real cited work.

## Pages

- `index.md` and `research_documentation_index.md` — navigation indices.
- `research_documentation.md` — the research documentation guide.
- `ant_colony_active_inference.md` — ant colony research write-up.

## Subfolders

- `active_inference/` — theory, applications, scaling, and hierarchical
  research notes.
- `architectures/` — continuous, hierarchical, multi-agent, and POMDP
  research notes.
- `complex_systems/` — adaptation, collective behavior, emergence, and
  self-organization notes.
- `methodology/` — hypothesis, sampling, validation, and variables guidance.
- `tools/` — analysis, documentation, and implementation tool notes.
- `examples/`, `guidelines/`, `implementations/`, `standards/`, `templates/`,
  `validation/` — container pages for related material.

## Relationship to the knowledge base

The conceptual research notes live under `knowledge_base/research/`; the
pages in this folder link to them and to the repository's executable
validation (`code/tests/`, manuscript reproducibility sections).
