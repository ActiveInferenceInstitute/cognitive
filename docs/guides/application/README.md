# Application guides index

Application guides explain domain-specific uses of Active Inference and the
repository's models.

## Pages

- `active_inference_spatial_applications.md` — spatial and geographic
  applications.
- `guide_for_cognitive_modeling.md` — general cognitive modeling guide.
- `parr_2022_chapter_6.md` — a study guide to the design workflow in Chapter 6 of
  Parr, Pezzulo, and Friston (2022).

## Rules

Application pages may be theoretical or domain-specific, but code examples
must use the public `cognitive` or `Things` packages, and external
environments supplying observations and actions must be named explicitly.
See `AGENTS.md` for the full rules.
