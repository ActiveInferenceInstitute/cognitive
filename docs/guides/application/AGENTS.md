# Application guide instructions

Application documentation may explain theoretical or domain-specific uses,
but code examples must use the public `cognitive` or `Things` packages. Do not
present domain-specific agent classes as part of this repository. For a
working integration, start with the root `README.md` or
`docs/manuscript/README.md` and state which external environment supplies
observations and actions.
