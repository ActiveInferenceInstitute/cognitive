# Learning paths index

The learning paths sequence Active Inference and cognitive-modeling topics
for study. They are educational, conceptual documents that reference
knowledge-base concepts and repository documentation.

## Navigation

- `index.md` — index of paths.
- `catalog_of_learning_paths.md` — the catalog of all paths.
- `navigation_framework_implementation.md` — how paths are organized.

## Path groups

- Core theory: `active_inference_learning_path.md`,
  `active_inference_mathematical_learning_path.md`,
  `active_inference_cognitive_learning_path.md`.
- Domains: biological, neuroscience, robotics, social, economic, ecological,
  environmental, security, quantum, spatial web, and more (see the catalog).
- Methods: computational, information theory, simulation, observation,
  experience, ethics, and pragmatism paths.

## Authoring

New paths must follow the rules in `AGENTS.md`: valid frontmatter, resolving
links, and registration in the catalog and index.
