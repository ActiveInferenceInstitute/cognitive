# Extended RxInfer workflow notes

> This page describes an external project, RxInfer.jl, which is not part of this repository and is not used by the Python package. It summarizes the official documentation at <https://docs.rxinfer.com/stable/>; if the two differ, the official documentation is authoritative. Julia snippets on this page are not run here.

This page used to run to about 800 lines of Julia: system-boundary, uncertainty and requirements classes, a deployment manager, an operations manager and a monitoring system. None of these are part of RxInfer; they were invented code and were removed.

The accurate, usable content is in [[systems_engineering_guidebook]]. Recommendation: this page has nothing left to add and can be merged into that one.
