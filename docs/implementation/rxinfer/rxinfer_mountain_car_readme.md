# Mountain car with RxInfer

> This page describes an external project, RxInfer.jl, which is not part of this repository and is not used by the Python package. It summarizes the official documentation at <https://docs.rxinfer.com/stable/>; if the two differ, the official documentation is authoritative. Julia snippets on this page are not run here.

Mountain car is the control task in which an underpowered car must climb out of a valley by first moving away from the goal. RxInfer's examples site has an "Active inference mountain car" example in its advanced category: <https://examples.rxinfer.com/categories/advanced_examples/active_inference_mountain_car/>.

This repository contains no mountain car implementation and no results for it. An earlier version of this page presented model code, constraints, benchmark comparisons, ablation studies and robustness tests; none of them were produced here, and they were removed. Read the official example for the model and its outputs.
