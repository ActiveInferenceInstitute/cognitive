# AGENTS.md — `docs/okn/explanations/`

- Generated artifacts. Do not hand-edit; regenerate from the matching capture.
- Keep the explanation directory name equal to its capture's date and topic, and
  keep both paths in the CI step in step with the files.
- `--check` compares the generated explanation with the committed one, so a
  capture change means regenerating rather than patching prose.
- Do not add files to a dated directory.
