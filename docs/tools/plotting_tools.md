# Plotting tools

The package's plotting surface:

- `cognitive.MatrixPlotter` (`code/tools/src/visualization/matrix_plots.py`)
  — matrix and belief figures; writes to explicit output paths (temporary
  or caller-selected directories in tests).
- `Things.Continuous_Generic.ContinuousVisualizer` — Pillow-backed
  multi-frame GIF animation for the continuous agent.
- `cognitive.utils.visualization.network_viz` — deterministic knowledge
  graphs.

Visualization output is ignored by Git; figures referenced by the
manuscript are generated by `code/scripts/build_manuscript.py`.
