# Ant Colony Usage Example

The Ant Colony folder (`code/Things/Ant_Colony/`) is documentation-only in
this repository: it contains README and AGENTS pages but no runtime code.
There is no importable `ant_colony` package here.

## Runnable examples

For runnable examples of the installed packages, use:

- The root `README.md` — the canonical discrete Active Inference dispatcher
  example.
- `docs/manuscript/README.md` — the end-to-end executable manuscript
  (deterministic figures, benchmarks, and rendering).
- `docs/examples/README.md` — example commands.
