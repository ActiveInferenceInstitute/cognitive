# Ant colony API

There is no importable ant colony API. `code/Things/Ant_Colony/` contains
documentation only (`README.md`, `AGENTS.md`, `Ant_Colony_README.md`) and no
Python modules; the `Things` package installs only `Things.Simple_POMDP` and
`Things.Continuous_Generic`. See [[code/Things/AGENTS|Things index]] for the
current status of each folder and [[agent_api]] for the agents that do exist.
