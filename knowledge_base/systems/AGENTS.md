# System-Level Agent Documentation

The systems domain collects systems-theory concepts used across the
framework: complex systems, emergence, self-organization, network theory,
dynamical systems, and adaptive systems, including social-ecological
treatments.

## Documents

The folder contains the domain's concept pages (every page is listed in
[[knowledge_base/systems/catalog|catalog]]; `README.md` gives the guided
navigation). Core entries include complex systems,
dynamical systems, control systems, adaptive systems, and social-ecological
systems.

## Notes

- The pages are conceptual; pseudocode within them is illustrative and is not
  package API.
- Multi-agent and swarm material is linked to design notes in `code/Things/`
  (for example `Ant_Colony`); those folders hold documentation, not code.
- Authoring rules for knowledge-base pages are in
  `knowledge_base/AGENTS.md`.
