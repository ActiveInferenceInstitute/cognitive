# IC Algorithm

## Overview
The IC (Inductive Causation) algorithm is a procedure from Verma and Pearl for deriving causal structure from a probability distribution. Given the conditional independence relations of a distribution that is generated by some directed acyclic graph (DAG), it returns a **pattern**: a partially directed graph that represents the whole class of DAGs that cannot be told apart from observational data. It is stated in Pearl (2009) in a form that does not specify how independences are tested, so it is a statement of what is identifiable. The PC algorithm is an efficient implementation of the same logic (see [[pc_algorithm]]).

## Equivalence of causal models
The algorithm rests on a graphical characterisation of observational equivalence. Verma and Pearl (1990) showed that two DAGs imply the same set of conditional independences exactly when they have the same skeleton (the same adjacencies, ignoring direction) and the same v-structures (triples $a\to c\leftarrow b$ in which $a$ and $b$ are not adjacent). Hence data on independences can recover the skeleton and the v-structures, and nothing about the directions of other edges beyond what those force.

## Procedure
The input is a distribution $P$ over variables $V$, assumed to be generated by a DAG and faithful to it (stable in Pearl's terminology).
1. **Adjacencies.** For each pair $a,b$, search for a set $S_{ab}\subseteq V\setminus\{a,b\}$ with $a\perp\!\!\!\perp b\mid S_{ab}$. If no such set exists, join $a$ and $b$ by an undirected edge.
2. **V-structures.** For each pair of non-adjacent variables $a,b$ with a common neighbour $c$, orient $a\to c\leftarrow b$ if $c\notin S_{ab}$.
3. **Propagation.** Orient as many of the remaining undirected edges as possible, subject to two constraints: no new v-structure may be created, and no directed cycle may appear.

The result is the pattern. Edges left undirected are those whose direction is not determined by the independence structure. Pearl (2009) also presents a variant for the case in which unobserved common causes may exist, in which the output is a richer marked graph.

## Relation to the PC algorithm
Step 1 above searches over all candidate conditioning sets, which is exponential in the number of variables. PC reaches the same pattern under the same assumptions by testing sets in order of increasing size and restricting them to neighbours, which is practical for sparse graphs. For an exact account of the assumptions of faithfulness and causal sufficiency, see [[pc_algorithm]] and Spirtes, Glymour and Scheines (2000).

## Relation to Active Inference
The link is conceptual. Structure learning in Active Inference is usually done by Bayesian model comparison, scoring candidate generative models by their evidence. The IC algorithm is a constraint-based alternative that infers structure from independence relations alone, and it is not part of the standard Active Inference formulation.
