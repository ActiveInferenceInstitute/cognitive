# Population Games

## Overview
A population game models strategic interaction among a large number of agents, each of whom has negligible influence on the outcome. The population is described by the proportions of agents using each strategy, and payoffs depend on those proportions. The framework unifies classical evolutionary game theory with models of learning and imitation in economics, and it separates the payoff structure of the game from the rule by which agents revise their choices.

## Formal setup
- **Strategies and states.** A single population has strategy set $S=\{1,\dots,n\}$. A population state is a vector $x$ in the simplex $\Delta=\{x\in\mathbb{R}^n_{\ge0}:\sum_ix_i=1\}$, where $x_i$ is the share playing strategy $i$ ([[probability_simplex]]).
- **Payoffs.** A payoff function $F:\Delta\to\mathbb{R}^n$ assigns $F_i(x)$ to strategy $i$. In a random-matching game with payoff matrix $A$, $F(x)=Ax$ is linear. Congestion games give nonlinear $F$.
- **Nash equilibrium.** A state $x^*$ is a Nash equilibrium if every strategy in use earns the maximum payoff: $x^*_i>0$ implies $F_i(x^*)=\max_jF_j(x^*)$.
- **Special classes.** In a potential game, $F=\nabla f$ for some function $f$, and local maxima of $f$ are equilibria. In a stable game, $(y-x)\cdot(F(y)-F(x))\le0$ for all states, which guarantees that the set of equilibria is convex.

## Revision protocols and dynamics
Agents occasionally revise strategies according to a revision protocol, giving conditional switch rates $\rho_{ij}(F(x),x)$ from $i$ to $j$. For large populations, the resulting stochastic process is approximated by a mean dynamic
$$\dot x_j=\sum_ix_i\rho_{ij}-x_j\sum_i\rho_{ji}.$$
Pairwise proportional imitation yields the replicator dynamic $\dot x_i=x_i\big(F_i(x)-\sum_jx_jF_j(x)\big)$ ([[replicator_dynamics]]). Other protocols give the best-response, logit and Smith dynamics. Rest points of the replicator dynamic include Nash equilibria, and stability results differ across protocols and game classes.

## Relation to Active Inference
The connection is by analogy. Population games describe the aggregate dynamics of many adaptive agents, as in [[evolutionary_game_theory]], whereas Active Inference describes the inference and action of one agent with a generative model. A formal bridge exists in that replicator dynamics can be derived as a form of Bayesian belief updating on a simplex, a connection discussed in the literature on evolutionary and Bayesian dynamics, but it is a mathematical correspondence, not evidence that populations perform inference. Multi-agent Active Inference models can instead be viewed as games between agents, see [[game_theory]].
