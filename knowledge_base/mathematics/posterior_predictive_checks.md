# Posterior Predictive Checks

## Overview
A posterior predictive check asks whether data generated by a fitted Bayesian model resemble the data actually observed. If the model is adequate, replicated datasets $y^{\mathrm{rep}}$ drawn from it should look statistically similar to the observed $y$. Systematic discrepancies indicate aspects of the data that the model does not capture. The approach is a tool for model criticism, not for selecting among models, and it follows from the view of Rubin (1984) and Gelman, Meng and Stern (1996).

## Procedure
The posterior predictive distribution is
$$p(y^{\mathrm{rep}}\mid y)=\int p(y^{\mathrm{rep}}\mid\theta)\,p(\theta\mid y)\,d\theta.$$
In practice, the check proceeds in four steps:
1. Draw parameter samples $\theta^{(s)}$ from the posterior, typically by [[markov_chain_monte_carlo]].
2. For each sample, simulate a replicated dataset $y^{\mathrm{rep},(s)}\sim p(y\mid\theta^{(s)})$.
3. Choose a test quantity or discrepancy $T(y,\theta)$ that targets a feature of interest, such as the maximum, the proportion of zeros, residual autocorrelation or a goodness-of-fit statistic.
4. Compare the distribution of $T(y^{\mathrm{rep}},\theta)$ with $T(y,\theta)$, graphically or through the posterior predictive $p$-value
$$p_B=\Pr\big(T(y^{\mathrm{rep}},\theta)\ge T(y,\theta)\mid y\big).$$

Values of $p_B$ near $0$ or $1$ indicate misfit in the dimension probed by $T$. Because the data are used both to fit the model and to test it, $p_B$ is not uniformly distributed under a correct model and tends to be conservative, so it is better read as a diagnostic than as a formal hypothesis test (Gelman et al., 2013). Prior predictive checks apply the same logic before fitting, using the prior $p(\theta)$ in place of the posterior to assess whether a model can produce plausible data. Cross-validated predictive checks ([[cross_validation]]) avoid the double use of data.

## Relation to Active Inference
Active Inference models are generative models, so the same logic applies when fitting them to behavioural or neural data: simulate responses from the fitted parameters and compare them with the observed choices or time courses. Model comparison in that setting usually relies on variational free energy as an approximation to [[model_evidence]], which ranks models but does not reveal whether the best model is adequate. Predictive checks supply that second question. This is standard Bayesian workflow applied to Active Inference rather than a feature of the theory itself.
