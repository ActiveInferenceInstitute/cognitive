# BioFirm Knowledge Base Documentation

BioFirm is a biological firm theory: organizational and ecological systems
described through the free energy principle and active inference. This folder
collects the framework documents, schema notes, and ecological applications.

## Documents

- [[biofirm_framework]] — the BioFirm framework definition.
- [[biofirm_schema]] — schema and modeling conventions.
- [[active_inference_connections]] and [[biofirm_active_inference_connections]]
  — connections between BioFirm and active inference.
- [[bioregional_state_space]] — state-space treatment of bioregions.
- [[ecological_active_inference]] and [[socioeconomic_active_inference]] —
  domain applications.
