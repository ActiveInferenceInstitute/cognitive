# Memory Systems


## Overview

Memory Systems comprise the neural mechanisms and cognitive processes that enable the encoding, storage, and retrieval of information. These systems form a complex hierarchy of interacting components that support different aspects of memory function, from brief sensory traces to lifelong knowledge.

## Core Memory Systems

### Working Memory

- [[working_memory]] - Short-term active maintenance

  - [[central_executive]] - Attention-directing control of working memory

    - [[attention_control]] - Focus management

    - [[task_switching]] - Goal shifting

    - [[interference_control]] - Distraction handling

  - storage systems - Short-term stores for verbal and visual information

    - [[phonological_loop]] - Rehearsal of verbal information

    - [[visuospatial_sketchpad]] - Visual-spatial info

    - [[episodic_buffer]] - Multimodal integration

### Declarative Memory

- [[explicit_memory]] - Conscious recollection

  - [[episodic_memory]] - Event memory

    - [[autobiographical_memory]] - Personal events

    - [[source_memory]] - Memory for where and when information was learned

    - temporal memory - Memory for temporal order of events

  - [[semantic_memory]] - Factual knowledge

    - conceptual knowledge - Abstract concepts

    - categorical knowledge - Knowledge of category membership

    - world knowledge - General facts

### Non-declarative Memory

- [[implicit_memory]] - Memory expressed without conscious recall

  - [[procedural_memory]] - Skills and habits

    - [[motor_skills]] - Learned motor sequences

    - [[cognitive_skills]] - Learned mental procedures

    - behavioral habits - Routine actions

  - [[priming]] - Faster processing after prior exposure

    - [[perceptual_priming]] - Form-based

    - [[conceptual_priming]] - Meaning-based

    - associative priming - Relationship-based

## Neural Implementation

### Anatomical Structures

- [[medial_temporal_lobe]] - Medial temporal region supporting declarative memory

  - [[hippocampus]] - Binds elements into episodic memories

    - [[dentate_gyrus]] - Pattern separation

    - [[ca3]] - Pattern completion

    - [[ca1]] - Temporal integration

  - [[entorhinal_cortex]] - Gateway between neocortex and hippocampus

    - [[grid_cells]] - Neurons with periodic spatial firing fields

    - [[time_cells]] - Neurons encoding elapsed time

### Circuit Mechanisms

- [[memory_circuits]] - Neural circuits supporting memory

  - encoding circuits - Circuits that capture new information

    - [[attention_networks]] - Attention networks selecting information to encode

    - novelty detection - Detecting novel or significant events

  - consolidation circuits - Circuits stabilizing memories after encoding

    - [[hippocampal_cortical]] - Hippocampus-neocortex interactions that stabilize memory

    - [[synaptic_consolidation]] - Synapse-level stabilization of memory traces

### Molecular Mechanisms

- molecular memory - Cellular and molecular basis of memory

  - [[synaptic_plasticity]] - Connection changes

    - [[ltp]] - Long-term potentiation of synapses

    - [[ltd]] - Long-term depression of synapses

  - [[protein_synthesis]] - Protein production sustaining memory traces

    - immediate early genes - Genes rapidly activated by neural activity

    - [[structural_proteins]] - Proteins supporting synaptic structure

### Encoding

- [[memory_encoding]] - Initial registration

  - [[attention_mechanisms]] - Attention selecting what is encoded

    - [[bottom_up_attention]] - Stimulus-driven

    - [[top_down_attention]] - Goal-directed

  - [[elaborative_encoding]] - Deep processing

    - semantic elaboration - Meaning-based

    - self reference - Personal relevance

### Consolidation

- [[memory_consolidation]] - Stabilization

  - [[synaptic_consolidation]] - Synapse-level changes stabilizing memory

    - [[protein_synthesis]] - Molecular basis

    - synaptic remodeling - Structural changes

  - [[systems_consolidation]] - Gradual reorganization across brain networks

    - hippocampal independence - Memory retrievable without the hippocampus

    - cortical integration - Integration of memories into cortical knowledge

### Retrieval

- [[memory_retrieval]] - Access processes

  - recall - Active reconstruction

    - [[free_recall]] - Recall without cues

    - [[cued_recall]] - Recall aided by cues

  - recognition - Judging whether an item was encountered before

    - [[recollection]] - Retrieval of specific contextual details

    - [[familiarity]] - Sense of prior occurrence without details

## Memory Properties

### Organization

- [[memory_organization]] - Structure of stored memories

  - [[hierarchical_organization]] - Memories arranged in nested levels

    - categorical structure - Grouping of items into categories

    - associative networks - Linked memory representations

  - schema organization - Knowledge frameworks

    - mental models - Internal representations of how things work

    - scripts - Event sequences

### Dynamics

- memory dynamics - Changes in memory over time

  - forgetting - Information loss

    - decay - Time-based

    - [[interference]] - Competition-based

  - [[reconsolidation]] - Memory update

    - destabilization - Retrieved memory becomes unstable

    - restabilization - Memory re-stabilization after reactivation

### Characteristics

- memory features - Qualities that describe memories

  - specificity - Level of detail retained

    - [[gist]] - Core meaning

    - verbatim - Exact details

  - durability - Persistence

    - strength - How firmly a memory is stored

    - accessibility - Retrieval ease
