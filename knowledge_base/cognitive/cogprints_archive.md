## CogPrints Archive

### Overview

CogPrints was an open electronic archive of cognitive science papers, covering psychology, neuroscience, linguistics and computer science, with some philosophy. It worked on the self-archiving model: authors deposited their own preprints and postprints, which were then freely readable. It is a literature source, not a dataset or a software dependency.

### What It Is Good For

CogPrints is useful for the cognitive-science background that Active Inference builds on: perception, memory, language, attention and the philosophy of mind, much of it from the era before the free-energy principle became a common frame. A paper found there can supply the empirical phenomenon or the classical model that a page in this vault then reinterprets in Active Inference terms. For example, work on attention, memory or sensorimotor coupling can be set beside [[knowledge_base/cognitive/attention_mechanisms]], [[knowledge_base/cognitive/memory_systems]] or [[knowledge_base/cognitive/sensorimotor_coordination]].

### Limits

CogPrints is not an Active Inference or free-energy source. Recent work in that area is mostly published in journals and on general preprint servers, so the archive should not be cited as evidence for any claim about the framework itself. Before relying on a specific record, check that the item is still retrievable and prefer the published version of record where one exists. This page does not verify the archive's present availability.

### Relation To This Repository

Nothing in the code or the knowledge base mirrors or depends on CogPrints. The only inbound reference is the entry in [[cognitive/index]]. Reading lists and course material are collected on [[knowledge_base/cognitive/mit_computational_cognitive_science]] and [[knowledge_base/cognitive/mathematical_cognition_bibliography]]; per-work citation notes are kept in the `knowledge_base/citations` directory.
