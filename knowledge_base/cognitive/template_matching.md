# Template Matching

## Overview
Template matching is a model of recognition in which an input is compared against stored patterns, and the stored pattern with the best match decides the category. It is the simplest account of [[pattern_recognition]], used in early cognitive psychology as a strawman and in engineering as a working method.

## Formalism
For an input patch $x$ and template $t$ of equal size, a common match score is the normalised cross-correlation
$$ r = \frac{\sum_i (x_i - \bar{x})(t_i - \bar{t})}{\sqrt{\sum_i (x_i - \bar{x})^2 \sum_i (t_i - \bar{t})^2}} $$
which ranges from $-1$ to $1$ and is invariant to the brightness and contrast of the input. In signal detection, the matched filter is the linear filter that maximises signal-to-noise ratio for a known signal in white Gaussian noise, and it amounts to correlating the input with the template ([[signal_detection]]).

## Limits and descendants
- **Variability.** A rigid template fails when the input changes in size, orientation, or style, so a literal account would need a template for every variant. Letters in different fonts or hand-written forms illustrate this.
- **Storage.** The number of templates grows with the number of variants; it is not clear how the right one would be selected without a search that presupposes recognition.
- **Alternatives.** Feature-analysis models decompose input into parts, and prototype models match against averages of category members ([[feature_extraction]]). Structural description models match relations between parts.
- **Where it survives.** Template-like matching fits cases with little variation, such as matching to a target held in mind during visual search, where an attentional template biases processing toward the target's features ([[feature_based_attention]]).

## Role in Active Inference
The relation to Active Inference is a contrast as much as a connection. A top-down prediction in predictive coding resembles a template, and a good match means small [[prediction_error]]. But the prediction is generated by a generative model that can vary with context, pose, and scale, rather than retrieved as a fixed image, and inference revises the hypothesis rather than only scoring stored ones. Matched filtering can be recovered as a limiting case of Bayesian inference under Gaussian noise with a known signal.
