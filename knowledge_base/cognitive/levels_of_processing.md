# Levels of Processing

## Overview
Levels of processing is a framework proposed by Craik and Lockhart (1972) as an alternative to models that divide memory into separate stores. It holds that the durability of a memory trace is a by-product of the depth to which a stimulus was analysed at encoding. Shallow analysis, such as the visual shape of a printed word, leaves a weaker trace than deeper semantic analysis of its meaning.

## Evidence
In the standard experimental paradigm, participants answer orienting questions about a list of words without knowing that memory will be tested. Questions concern physical features (is the word in capital letters?), sound (does it rhyme with a given word?) or meaning (does it fit a sentence?). Later recall and recognition are generally lowest after the structural questions and highest after the semantic ones. Craik and Tulving (1975) reported this pattern across several experiments. Related findings show that self-referential and elaborative encoding also improve retention, and the framework helped motivate research on elaboration and on the role of distinctiveness.

## Criticism
A main criticism is circularity: depth was defined independently of the memory outcome only by intuition, so deeper processing risked being identified by the fact that it produced better memory. Another is that deep processing does not always yield better performance. Morris, Bransford and Franks (1977) showed that the appropriate type of encoding depends on the retrieval task, so that rhyme-based encoding can outperform semantic encoding when the test asks about rhyme. This view, transfer-appropriate processing, emphasises the match between encoding and retrieval operations. Today the framework is viewed as a useful heuristic and not a full theory.

## Relation to Active Inference
The connection is an analogy. Deeper encoding corresponds loosely to integrating an item into a richer, more structured generative model, so that more routes to recovering it exist. Active Inference does not currently provide a formal account of the levels-of-processing effect.
