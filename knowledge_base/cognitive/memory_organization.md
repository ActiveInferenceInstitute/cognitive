# Memory Organization


## Overview

Memory Organization encompasses the structural and functional principles by which cognitive systems organize, store, and access information. This framework describes how different memory systems interact and how knowledge is hierarchically structured to support efficient storage and retrieval.

## Core Components

### Memory Systems Architecture

- memory hierarchy - Organization of memory into tiers

  - [[sensory_memory]] - Very brief storage of sensory input

    - [[iconic_memory]] - Fleeting visual sensory store

      - [[visual_persistence]] - Brief retention of visual images

      - feature storage - Holding basic features of stimuli

    - [[echoic_memory]] - Fleeting auditory sensory store

      - auditory persistence - Brief retention of sound traces

      - phonological storage - Short-term holding of speech sounds

  - [[working_memory]] - Temporary storage for active manipulation

    - [[central_executive]] - Attention-directing control component

      - [[attention_control]] - Directing and sustaining focus

      - [[coordination]] - Combining information across memory components

    - storage buffers - Temporary holding stores

      - [[phonological_loop]] - Rehearsal of verbal and auditory information

      - [[visuospatial_sketchpad]] - Holding visual and spatial information

      - [[episodic_buffer]] - Binding multimodal information into episodes

### Knowledge Organization

- knowledge structure - How stored knowledge is arranged

  - semantic organization - Arrangement of knowledge by meaning

    - category structure - Organization of concepts into categories

      - hierarchical categories - Nested categories from general to specific

      - [[prototype_effects]] - Best examples representing a category

    - associative networks - Networks of linked concepts

      - semantic relations - Meaning-based links between concepts

      - context associations - Links between items and settings

  - episodic organization - Arrangement of memories of events

    - temporal organization - Ordering of memories in time

      - sequence memory - Memory for the order of events

      - timeline structure - Placing events along a temporal scale

    - spatial organization - Arrangement of memories by location

      - [[cognitive_maps]] - Internal representations of spatial layout

      - navigation memory - Memory supporting route finding

### Memory Integration

- memory integration - Combining information across memory systems

  - cross system binding - Linking content across memory systems

    - declarative binding - Linking facts and events

      - episode semantic - Linking specific events to general facts

      - fact procedure - Linking factual and procedural knowledge

    - implicit binding - Unconscious linking across memory systems

      - skill knowledge - Knowledge expressed through performance

      - habit memory - Memory for learned routines

  - [[consolidation_processes]] - Stabilization of memories after learning

    - [[synaptic_consolidation]] - Cellular stabilization of new synaptic changes

      - molecular changes - Protein and gene-expression changes at synapses

      - [[structural_changes]] - Physical remodeling of synapses

    - [[systems_consolidation]] - Gradual reorganization of memory across brain regions

      - [[hippocampal_cortical]] - Transfer of memories from hippocampus to cortex

      - distributed storage - Memory spread across many brain regions

## Neural Implementation

### Storage Networks

- [[memory_networks]] - Brain regions supporting memory

  - [[local_circuits]] - Short-range connections among neighboring neurons

    - [[cortical_columns]] - Vertical groups of cortical neurons

      - minicolumn organization - Narrow vertical chains of neurons

      - [[hypercolumn_structure]] - Clusters of columns covering one input location

    - layer organization - Arrangement of cortical layers

      - laminar circuits - Connections within and between cortical layers

      - interlaminar connections - Links between cortical layers

  - distributed networks - Long-range connections across brain regions

    - hub networks - Highly connected integrating regions

      - [[convergence_zones]] - Regions combining inputs from multiple areas

      - integration hubs - Regions joining information from several systems

    - parallel networks - Multiple pathways handling similar functions

      - redundant storage - Duplicate encoding for reliability

      - complementary systems - Systems with different, mutually supporting roles

### Circuit Mechanisms

- [[memory_circuits]] - Neural pathways that support remembering

  - encoding circuits - Circuits forming new memories

    - [[pattern_separation]] - Making similar inputs distinct

      - orthogonalization - Making representations non-overlapping

      - [[sparse_coding]] - Representing items with few active neurons

    - [[pattern_completion]] - Recovering whole memories from partial cues

      - [[attractor_dynamics]] - Network settling into stored patterns

      - associative recall - Retrieval triggered by linked cues

  - maintenance circuits - Circuits keeping memories active

    - [[reverberatory_circuits]] - Loops that sustain activity

      - [[recurrent_networks]] - Networks with feedback connections

      - sustained activity - Persistent firing that holds information

    - stabilization circuits - Circuits that preserve memory traces

      - [[synaptic_tagging]] - Marking synapses for later strengthening

      - [[protein_synthesis]] - Protein production needed for lasting memory

### Access Mechanisms

- memory access - Mechanisms for reaching stored memories

  - retrieval circuits - Circuits that recover stored memories

    - search processes - Seeking target memories among stored ones

      - [[spreading_activation]] - Activation passing to related items

      - parallel search - Simultaneous checking of many memories

    - selection processes - Choosing among candidate memories

      - competition - Rivalry among candidate memories

      - [[inhibition]] - Suppressing competing memories

  - integration circuits - Circuits combining information from several sources

    - binding circuits - Circuits linking features into wholes

      - [[temporal_binding]] - Linking items occurring close in time

      - [[feature_binding]] - Combining features into a unified item

    - updating circuits - Circuits that revise stored memories

      - modification - Altering existing memory content

      - [[reconsolidation]] - Re-stabilization of memories after retrieval

## Organizational Principles

### Hierarchical Structure

- memory hierarchy - Ordering of memory by abstraction and control

  - [[abstraction_levels]] - Degrees of detachment from specifics

    - concrete representations - Representations tied to specific details

      - perceptual features - Sensory properties of experience

      - motor patterns - Stored movement sequences

    - abstract representations - Representations independent of specific details

      - concepts - General ideas grouping related instances

      - [[schemas]] - Organized knowledge frameworks for situations

  - processing levels - Degrees of control and depth in processing

    - [[automatic_processing]] - Fast, effortless processing

      - habit level - Routine, cue-driven responding

      - skill level - Practiced, fluent performance

    - controlled processing - Slow, effortful, deliberate processing

      - strategic level - Planning and goal-directed processing

      - metacognitive level - Monitoring one's own memory

### Network Organization

- [[memory_networks]] - Network-level organization of memories

  - local organization - Structure among nearby items

    - feature clusters - Items grouped by shared features

      - similarity organization - Grouping by similarity

      - proximity organization - Grouping by closeness in space or time

    - functional clusters - Items grouped by use

      - task organization - Grouping by task demands

      - context organization - Grouping by setting

  - global organization - Broad structure across the whole memory

    - [[distributed_representation]] - Information spread across many units

      - [[redundancy]] - Duplicate coding that protects against loss

      - complementarity - Different systems supporting each other

    - hierarchical representation - Nested levels of stored information

      - [[bottom_up]] - Processing driven by sensory input

      - [[top_down]] - Processing driven by expectations and goals

### Dynamic Properties

- memory dynamics - Change in memory over time

  - [[plasticity_mechanisms]] - Processes that alter synaptic strength

    - [[hebbian_plasticity]] - Strengthening of co-active connections

      - correlation learning - Learning from co-occurring activity

      - competition learning - Learning where units compete to respond

    - [[homeostatic_plasticity]] - Adjustments that keep activity balanced

      - [[scaling]] - Proportional adjustment of synaptic strengths

      - [[metaplasticity]] - Plasticity that depends on prior activity

  - stability mechanisms - Processes that preserve memories

    - maintenance processes - Activities that keep memories intact

      - reactivation - Replay of stored memory patterns

      - repair - Restoring damaged memory traces

    - protection processes - Processes that guard against loss

      - [[interference_control]] - Reducing disruption from similar memories

      - decay prevention - Preventing fading of stored traces
