# False Belief

## Overview
A false belief is a representation of the world held by an agent that does not match reality, for example believing an object is in a place it has since been moved from. Understanding that others can hold false beliefs requires representing beliefs as mental states that can differ from reality and from one's own knowledge. False-belief tasks are therefore treated as a core test of theory of mind.

## Tasks and findings
**Change-of-location task.** Wimmer and Perner (1983) introduced the paradigm in which a character places an object in one location and leaves; in the character's absence the object is moved. The child is asked where the character will look. The Sally-Anne version, used by Baron-Cohen, Leslie and Frith (1985), is the best-known variant. Answering correctly requires predicting action from the character's belief and not from the true location.

**Unexpected-contents task.** A child sees that a familiar container holds something unexpected, then is asked what another person will think is inside.

**Developmental pattern.** Children typically pass standard verbal tasks at around four to five years, with younger children tending to answer from their own knowledge. A meta-analysis found that performance improved with age across many task variants (Wellman, Cross and Watson, 2001). Children with autism spectrum conditions more often fail these tasks at ages when typically developing children pass, which motivated the theory-of-mind account of autism, though that account has since been debated and refined.

**Implicit tasks.** Looking-time and anticipatory-gaze studies report sensitivity to false beliefs in infants (Onishi and Baillargeon, 2005). Interpretation is contested, because replications have been mixed and it is unclear whether such responses reflect belief representation or simpler processes.

Neuroimaging links false-belief reasoning to a network including the temporoparietal junction and medial prefrontal cortex.

## Role in Active Inference
In Active Inference, attributing a belief to another agent is a form of inference about the hidden state of a generative process, namely another agent whose actions are caused by their own beliefs. Representing a false belief requires a model in which the other agent's beliefs are separate latent variables that can diverge from the true state. Friston and Frith (2015) discussed communicating agents sharing generative models. Models of recursive belief attribution have been simulated, but the account is a research programme, with empirical work on children's performance still at an early stage.
