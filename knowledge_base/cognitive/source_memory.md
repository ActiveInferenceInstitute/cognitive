# Source Memory

## Overview
Source memory is memory for the context in which something was learned: the speaker, the place, the modality, or whether the event was perceived, imagined, or inferred. It is separable from item memory, since one can recognise a fact and not know where it came from. It is typically classed as a component of [[episodic_memory]], and it depends on binding content to context.

## Source monitoring
The dominant framework, source monitoring (Johnson, Hashtroudi, and Lindsay), proposes that source is not stored as a label. Instead, people judge origin at retrieval by evaluating the qualities of a memory, such as perceptual detail, spatial and temporal context, semantic detail, and records of cognitive operations, against criteria suited to the decision.
- **Reality monitoring** distinguishes externally perceived from internally generated memories. Imagining an event vividly can later make it be misattributed to experience.
- **Internal source monitoring** distinguishes self-generated sources (thought versus said).
- **External source monitoring** distinguishes outside sources (which of two speakers said it).
- **Characteristic errors.** Source misattribution, cryptomnesia (an idea taken as one's own), and the false-fame effect, in which previously heard names seem famous, all come from accepting familiarity without its origin.
- **Neural correlates.** Source judgments are associated with hippocampal binding and with prefrontal evaluation and monitoring; reduced frontal function and ageing are linked to more source errors.

## Role in Active Inference
Source memory can be framed as inference about the cause of a mental content: is this representation driven by sensory input, or generated by the model itself? Models in which agents infer the reliability and origin of their own beliefs invoke [[metacognition]] and precision-weighting ([[precision_weighting]]). Accounts of hallucination and reality-monitoring disorders in [[computational_psychiatry]] use related ideas, namely a misallocation of precision between prior and sensory evidence. This is an active research programme and the mapping to the behavioural source monitoring literature is largely conceptual.
