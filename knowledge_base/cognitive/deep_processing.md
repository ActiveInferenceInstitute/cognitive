# Deep Processing

## Overview
Deep processing is encoding that concentrates on the meaning of material and its relations to what the learner already knows. It is contrasted with shallow processing, which concentrates on surface features such as the appearance or sound of a word. In the levels-of-processing framework of Craik and Lockhart (1972), the durability of a memory trace is a function of the depth of analysis at encoding, not of the amount of time spent or of the memory store involved.

## Evidence
In orienting-task experiments, participants answer a question about each word without knowing a memory test will follow. Structural questions ("is it in capital letters?") and phonemic questions ("does it rhyme with weight?") produce poorer later recall and recognition than semantic questions ("does it fit in this sentence?"). Craik and Tulving (1975) found this advantage across several tasks. Within semantic processing, richer or more elaborate encoding, in which an item is linked to many other ideas, further improves memory, and self-referential encoding is particularly effective.

## Criticisms and refinements
- **Circularity.** Without an independent measure of depth, the claim that deep processing yields better memory risks being defined by the outcome it predicts.
- **Transfer-appropriate processing.** Morris, Bransford and Franks (1977) showed that shallow, rhyme-based encoding can outperform semantic encoding when the test is a rhyme-recognition test, so benefit depends on the match between encoding and retrieval.
- **Maintenance rehearsal.** Repeating an item without elaboration helps little for long-term retention, although it maintains it in working memory.

## Relation to Active Inference
There is no established Active Inference model of levels of processing. A loose analogy treats deep encoding as integrating an input into a richer generative model with many connections, so that more cues can later lead back to it. This is a speculative reading, not a result of the framework.
