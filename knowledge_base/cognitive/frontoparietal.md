# Frontoparietal Network

## Overview
"Frontoparietal" refers to interconnected regions of lateral prefrontal and posterior parietal cortex that are co-activated across many demanding cognitive tasks. The term is used for several overlapping systems, so the sense used matters: the frontoparietal control network that adapts to task goals, the dorsal and ventral attention networks that include frontal and parietal nodes, and the frontoparietal regions invoked in theories of consciousness.

## Systems and findings
**Control network.** Resting-state connectivity identifies a frontoparietal control system, including dorsolateral and anterior prefrontal cortex and the intraparietal sulcus, distinct from the default mode network and the dorsal attention network (Vincent et al., 2008). Dosenbach et al. (2008) proposed a dual-network architecture in which a frontoparietal network initiates and adjusts control on a short timescale while a cingulo-opercular network provides stable set maintenance. Cole et al. (2013) found that its regions are flexible hubs whose connectivity pattern changes with task demands, which supports the idea that the network helps to configure other systems.

**Attention networks.** Corbetta and Shulman (2002) distinguished a dorsal frontoparietal system (frontal eye fields and intraparietal sulcus) for goal-directed selection from a right-lateralised ventral system for detecting salient, unexpected events.

**Working memory.** Sustained activity in prefrontal and parietal regions during delays, and the load dependence of parietal responses, link the network to working memory capacity.

**Consciousness.** Global neuronal workspace theory proposes that a frontoparietal network broadcasts information, making it globally available, and associates conscious access with ignition in these regions (Dehaene and Changeux, 2011). Rival theories locate the neural correlates in posterior cortex, and the role of prefrontal cortex in conscious experience, as against report, remains contested.

## Role in Active Inference
Frontoparietal activity is interpreted as implementing top-down control by setting the precision of lower-level predictions. Attention, in this reading, is the optimisation of precision, and frontoparietal regions are proposed as sources of the precision signals that modulate sensory processing (Feldman and Friston, 2010). Parr and Friston (2017) modelled working memory and attentional selection as inference over a hierarchical model, linking sustained delay activity to maintained beliefs. These are model-based interpretations of imaging findings and not a unique account; the same data are explained within non-Bayesian theories of cognitive control.
