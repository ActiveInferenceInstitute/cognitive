# Visual Search

## Overview
Visual search is the task of locating a target item among other items, called distractors. It is an everyday activity, such as finding keys on a cluttered desk, and a standard laboratory paradigm for studying attention. In a typical experiment, participants report whether a target is present or absent, and the reaction time is measured as a function of set size, the number of items in the display. The slope of the function relating response time to set size indicates how efficiently search proceeds.

## Feature and conjunction search
Treisman and Gelade (1980) distinguished two cases. In feature search the target differs from distractors in a single basic feature, such as colour or orientation, and responses are fast and nearly independent of set size, which gives the impression that the target pops out. In conjunction search the target is defined by a combination of features, for example a red vertical bar among red horizontal and green vertical bars, and the time increases roughly linearly with set size. Their feature integration theory explained this by proposing that basic features are registered in parallel in separate maps, while binding them into objects requires spatial attention applied serially (see [[feature_integration]]).

## Later theories
Later work showed that the dichotomy is a continuum. Duncan and Humphreys emphasised target-distractor similarity and distractor heterogeneity, and Wolfe's Guided Search model proposes that parallel processing of features produces an activation map that guides attention toward likely targets, which then are inspected serially. Search is also affected by experience, expectation of the target's location, and scene context. In natural viewing, search is carried out with eye movements, and covert attention moves ahead of the gaze (see [[covert_attention]] and [[eye_movements]]).

## Relation to Active Inference
The link is an active research programme. In Active Inference, saccades are actions chosen to maximise expected information gain about hidden causes of the scene, so searching is a form of epistemic foraging. Friston and colleagues presented simulations in which an agent with a generative model of the scene chooses fixations that resolve uncertainty, and showed behaviour resembling visual search, including inhibition of return. These models reproduce qualitative features, and how well they predict human fixation patterns in detail is still being evaluated.
