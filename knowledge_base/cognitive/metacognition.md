# Metacognition


## Overview

Metacognition refers to the ability to monitor, evaluate, and control one's own cognitive processes. This "thinking about thinking" enables self-awareness of cognitive states, regulation of learning and problem-solving, and adaptive control of cognitive resources.

## Core Components

### Metacognitive Knowledge

- [[knowledge_types]] - Kinds of knowledge about one's own thinking

  - task knowledge - Knowing what a task demands

    - [[difficulty_awareness]] - Knowing how hard a task is

    - [[strategy_awareness]] - Knowing which strategies suit a task

  - [[self_knowledge]] - Knowing one's own abilities and limits

    - [[ability_awareness]] - Knowing what one can do

    - [[limitation_awareness]] - Knowing what one cannot do well

  - [[state_monitoring]] - Checking one's current mental state

    - [[error_detection]] - Noticing that a mistake has occurred

    - [[success_evaluation]] - Judging whether a goal was reached
