# Sensory Memory

## Overview
Sensory memory is the earliest stage of memory in classical information-processing models. It is a modality-specific register that holds a detailed but fleeting trace of sensory input, long enough for selected information to be passed to later stages. In the multi-store model of Atkinson and Shiffrin (1968), sensory registers feed a short-term store, which in turn exchanges information with long-term memory. The registers have large capacity but decay or are overwritten rapidly.

## Forms and evidence
The visual form, [[iconic_memory]], was demonstrated by Sperling (1960). When shown a grid of letters for a fraction of a second, observers could report only about four or five in whole report, but could report nearly any single row when it was cued by a tone just after the display disappeared. This showed that much more information was available than could be reported, and that availability faded within about a second. The auditory form is [[echoic_memory]], and analogous brief stores have been proposed for touch. Coltheart (1980) distinguished the persistence of a neural or visible trace from informational persistence, the information that remains usable, and argued that they should not be conflated.

## Role and limits
Sensory memory supports the stable perception of continuous events, since the system must integrate inputs over short intervals. It also provides the pool from which attention selects. What gets transferred is limited by attention, and unattended material is lost. The existence of distinct stores is debated, as is whether sensory memory reflects a separate memory system or the persistence of sensory processing itself, and the term should be read as a description of a stage rather than a single anatomical structure.

## Relation to Active Inference
The link is an analogy. In predictive-processing terms, inference about the present state of the world integrates recent sensory evidence with priors, so a short buffer of evidence, or temporal depth in the model, is needed to evaluate hypotheses that unfold over time. Evidence accumulation and belief updating over a short window are standard components of Active Inference models of perception. These models do not make claims specific to sensory memory as classically defined, and the framework is not a replacement for the empirical literature on the registers.
