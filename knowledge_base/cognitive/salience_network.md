# Salience Network

## Overview
The salience network is a large-scale intrinsic connectivity network whose core nodes are the anterior insula and the dorsal anterior cingulate cortex. Subcortical partners include the amygdala, ventral striatum, hypothalamus and thalamus. Seeley and colleagues (2007) identified it through resting-state functional connectivity and distinguished it from an executive control network centred on lateral frontal and parietal cortex.

## Functions
- **Detecting relevant events.** The network responds to events that are behaviourally important, whether through novelty, emotional significance, pain, or interoceptive change such as a racing heart. Its activity is therefore tied to the integration of bodily state with external events (see [[salience]]).
- **Network switching.** Sridharan and colleagues (2008) found that the right fronto-insular cortex exerts influence on the default mode network and the central executive network, and that it is engaged when control passes between them. Menon and Uddin (2010) described the insula as a hub that detects salient events and initiates control signals toward attention and working memory systems. Directional claims rest on statistical measures of connectivity, so causal interpretations should be cautious.
- **Clinical relevance.** Altered salience network connectivity is reported in anxiety, autism, schizophrenia, and frontotemporal dementia, though findings differ across studies and are rarely specific to one condition.

## Relation to Active Inference
Several authors interpret the network in predictive terms. The anterior insula is described as a hub of interoceptive inference, where bodily predictions and prediction errors are integrated with context (see [[interoception]]). Salience detection can then be cast as the allocation of precision, deciding which prediction errors are given weight and which hierarchy is allowed to dominate, a role that would match the observed switching between the default mode and executive networks. This is an interpretive proposal that links well to the empirical description but has not been derived from a validated model of the network itself.
