# Encoding

## Overview
In memory research, encoding is the first stage of remembering: the conversion of perceived or thought information into a representation that can be stored and later retrieved. It is followed by consolidation and storage, then retrieval. This page uses the memory sense; the neural sense, in which a stimulus is represented by spike patterns, is covered in neural_coding.

## Determinants
- **Attention.** Items must be attended to be encoded well; divided attention at study reduces later memory.
- **Depth of processing.** Semantic processing yields better memory than perceptual processing (Craik and Lockhart, 1972); see elaboration.
- **Organisation.** Grouping items into chunks, categories or stories improves encoding.
- **Encoding specificity.** Memory is best when the retrieval context matches the encoding context; the cue is effective only to the extent that it was encoded with the item (Tulving and Thomson, 1973).
- **Intention and effort.** Incidental learning can match intentional learning when processing is deep.

Information may be encoded in several codes: visual, phonological and semantic. Working memory maintains information over seconds and acts as a gateway, though maintenance alone is a weak route to durable memory.

**Neural basis.** Hippocampal and surrounding medial temporal lobe regions, together with prefrontal cortex, are central to episodic encoding. The subsequent memory paradigm sorts study-phase brain activity by whether each item is later remembered or forgotten, and finds greater activity in these regions for later-remembered items (Paller and Wagner, 2002). Synaptic mechanisms such as long-term potentiation are widely regarded as part of the cellular substrate, though the link between cellular and behavioural levels is an active research area.

In social insects, encoding is discussed in a broader sense, for instance as the storage of route or location information in individuals or in pheromone trails.

## Role in Active Inference
In Active Inference, learning is the updating of parameters of a generative model, so encoding corresponds to the posterior update that incorporates a new observation. Novel or surprising observations carry larger prediction errors and thus drive larger updates, and attention as precision weighting determines how strongly a stream affects learning. This is a formal reading of the process, not a model specific to the empirical findings above; some, such as encoding specificity, require additional assumptions about how contexts index stored traces.
