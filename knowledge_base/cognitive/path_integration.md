# Path Integration

## Overview
Path integration, also called dead reckoning, is the computation of current position relative to a reference point by summing successive displacements, using signals generated by the animal's own movement. Given the heading and distance of each step, the animal maintains a running vector to its starting point and can return along a direct route, even after a long and winding outward journey in unfamiliar terrain.

## Evidence
The classic demonstrations come from the desert ants of the genus *Cataglyphis*, which forage alone on featureless salt pans. After a convoluted outward path, they run almost straight toward the nest (Müller and Wehner, 1988). Heading is derived mainly from a celestial compass based on polarised skylight and the sun, and distance is derived from a step-counting odometer, shown by experiments in which the legs of ants were lengthened or shortened and return distances changed accordingly (Wittlinger, Wehner and Wolf, 2006). Path integration has also been demonstrated in honeybees, spiders, rodents and humans, where it draws on vestibular, proprioceptive and visual flow signals ([[proprioception]]).

## Properties and neural basis
Because each step adds a small error, the estimate drifts over time, and animals correct it using landmarks and familiar routes. In ants, path integration serves as a fallback and is combined with learned visual route memories, and in the central complex of insect brains there are neural circuits whose activity has been modelled as a vector memory. In mammals, grid cells in the entorhinal cortex, together with head-direction cells and place cells, are widely proposed to implement the integration of velocity, with landmarks resetting accumulated error (McNaughton et al., 2006); the details of that mechanism remain under study ([[grid_cells]]).

## Relation to Active Inference
The connection is a clear formal one, though not specific to Active Inference. Dead reckoning is a case of recursive Bayesian state estimation: velocity signals drive a prediction of the next position, uncertainty grows with each step, and landmark observations supply likelihood terms that reduce it. A generative model of this kind is a common building block of navigation models in the framework, in which an agent also acts to resolve uncertainty about its location, for example by approaching a landmark. Such models describe the computation but do not by themselves decide which neural implementation animals use.
