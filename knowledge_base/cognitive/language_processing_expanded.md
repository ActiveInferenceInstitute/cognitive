# Language Processing


## Overview

Language Processing encompasses the cognitive and neural mechanisms involved in comprehending, producing, and acquiring language. This system integrates multiple cognitive functions to enable the processing of linguistic information at various levels, from basic sound perception to complex discourse understanding.

## Core Components

### Phonological Processing

- sound processing - Perceiving and producing speech sounds

  - phoneme processing - Handling the smallest speech sound units

    - [[phoneme_recognition]] - Identifying phonemes in speech

      - acoustic analysis - Extracting acoustic features of speech

      - [[categorical_perception]] - Perceiving sounds as discrete categories

    - phoneme manipulation - Operating on speech sounds mentally

      - phonological awareness - Conscious knowledge of sound structure

      - [[phonological_memory]] - Short-term retention of speech sounds

  - prosodic processing - Processing speech melody and rhythm

    - [[intonation]] - Pitch variation across utterances

      - pitch contours - Pitch shapes across a phrase

      - stress patterns - Relative emphasis on syllables

    - rhythm - Temporal patterning of speech

      - temporal structure - Timing relations among speech units

      - meter - Regular alternation of stressed syllables

### Lexical Processing

- word processing - Handling words in comprehension and production

  - [[word_recognition]] - Identifying words from input

    - [[visual_word_form]] - Recognizing printed words

      - orthographic processing - Processing letter strings and spelling

      - morphological analysis - Decomposing words into meaningful parts

    - auditory word form - Recognizing spoken words

      - [[phonological_decoding]] - Mapping sounds onto word forms

      - [[lexical_access]] - Retrieving words from the mental lexicon

  - word production - Generating words for speech

    - word selection - Choosing the intended word

      - semantic activation - Activating meaning representations

      - [[lemma_retrieval]] - Retrieving abstract word entries

    - phonological encoding - Building the sound form of a word

      - syllable program - Selecting stored syllable motor programs

      - articulation plan - Planning speech movements

### Syntactic Processing

- grammar processing - Applying grammatical rules

  - [[syntactic_parsing]] - Assigning structure to sentences

    - phrase structure - Grouping words into phrases

      - constituent analysis - Identifying phrase constituents

      - hierarchical structure - Nested organization of phrases

    - dependency parsing - Identifying head-dependent word relations

      - grammatical relations - Syntactic links such as subject and object

      - [[thematic_roles]] - Who did what to whom

  - syntactic generation - Building sentence structure in production

    - sentence planning - Organizing a sentence before speaking

      - structural selection - Choosing a syntactic frame

      - [[word_order]] - Ordering words within the sentence

    - agreement processing - Matching grammatical features between words

      - [[feature_checking]] - Verifying features such as number and gender

      - [[constraint_satisfaction]] - Meeting multiple grammatical constraints at once

### Semantic Processing

- meaning processing - Interpreting meaning in language

  - word meaning - Meaning of individual words

    - lexical semantics - Meaning relations among words

      - [[sense_disambiguation]] - Choosing the right meaning of a word

      - polysemy resolution - Resolving words with multiple related meanings

    - [[conceptual_semantics]] - Concept-based meaning representations

      - category knowledge - Knowledge of category membership

      - feature knowledge - Knowledge of object properties

  - sentence meaning - Meaning of whole sentences

    - [[compositional_semantics]] - Combining word meanings into sentence meaning

      - [[predicate_argument]] - Who does what to whom

      - [[semantic_roles]] - Participant roles in events

    - inference generation - Deriving meaning beyond the literal text

      - logical inference - Drawing conclusions from stated information

      - pragmatic inference - Inferring speaker intent from context

## Processing Principles

### Information Flow

- language flow - Movement of information through language processing

  - [[bottom_up]] - Processing driven by sensory input

    - [[feature_extraction]] - Pulling out basic input features

      - acoustic features - Basic properties of the sound signal

      - visual features - Basic properties of the visual input

    - [[pattern_recognition]] - Identifying familiar patterns in input

      - [[template_matching]] - Matching input to stored templates

      - [[statistical_learning]] - Learning regularities from input

  - [[top_down]] - Processing driven by prior knowledge

    - prediction generation - Anticipating upcoming input

      - [[context_effects]] - Context shaping predictions

      - [[expectation_effects]] - Expectations shaping interpretation

    - constraint application - Using linguistic constraints to narrow interpretations

      - syntactic constraints - Grammatical limits on interpretation

      - semantic constraints - Meaning-based limits on interpretation

### Resource Management

- language resources - Cognitive resources used by language processing

  - [[attention_allocation]] - Distributing attention across tasks

    - [[selective_attention]] - Focusing on relevant input

      - [[target_selection]] - Choosing the relevant item

      - distractor suppression - Filtering out irrelevant input

    - [[sustained_attention]] - Maintaining focus over time

      - [[vigilance]] - Staying alert for rare events

      - fatigue management - Coping with declining mental resources

  - [[working_memory]] - Short-term holding and manipulation of information

    - [[phonological_loop]] - Temporary store for speech-based information

      - [[verbal_rehearsal]] - Silently repeating words to retain them

      - articulatory suppression - Blocking rehearsal by repeating irrelevant speech

    - [[executive_control]] - Supervising and coordinating processing

      - updating - Replacing contents of working memory

      - monitoring - Checking performance for errors

### Integration Mechanisms

  - cross level - Integration across linguistic levels

    - form meaning - Linking word form to meaning

      - syntax semantics - Linking grammar to meaning

    - [[time_integration]] - Combining information over time

      - [[temporal_binding]] - Linking events within a time window

      - sequence integration - Combining ordered elements into wholes

  - [[cross_modal]] - Integration across sensory modalities

    - [[audio_visual]] - Combining auditory and visual input

      - [[lip_reading]] - Using mouth movements to decode speech

    - gesture speech - Coordination of gesture with speech

      - [[deictic_gesture]] - Pointing gestures that indicate referents

      - grammatical deficits - Impaired use of grammar

      - [[processing_speed]] - Slowed language processing

    - reading disorders - Impairments of reading

      - [[dyslexia]] - Difficulty with word decoding

      - comprehension deficits - Impaired understanding of text
