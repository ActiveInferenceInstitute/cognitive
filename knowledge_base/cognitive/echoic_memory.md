# Echoic Memory

## Overview
Echoic memory is the auditory form of sensory memory: a brief, high-capacity store that holds a faithful trace of recent sound so that it can be processed after the stimulus has ended. The term was introduced by Neisser (1967) as the auditory counterpart of iconic memory. The store is needed because sounds, especially speech, unfold in time and can only be interpreted by relating present input to what came just before.

## Evidence
Darwin, Turvey and Crowder (1972) adapted Sperling's partial report method to hearing. Listeners heard three simultaneous lists of items from different spatial locations, and a visual cue indicated which list to report. Cued reports were better than expected from whole-report performance, suggesting that more material was briefly available than could be reported before it faded. The modality or suffix effect is a second line of evidence: a spoken irrelevant item at the end of a list impairs recall of the final items, a result interpreted as interference with precategorical acoustic storage (Crowder and Morton, 1969).

## Duration and neural correlates
Estimates of duration depend on the task and measure, with values from a few hundred milliseconds up to several seconds reported, and some authors distinguish a very short store from a longer one. Electrophysiological studies provide a neural index. The mismatch negativity is elicited by an occasional deviant sound among standards and requires a memory trace of the standard held for several seconds, which links it to this store (see [[erp]]). Sources are located in auditory cortex and also involve frontal regions.

## Relation to Active Inference
The connection is an analogy supported by modelling. The mismatch negativity has been interpreted as a prediction error arising because incoming sounds are compared with predictions built from recent auditory history, so the memory trace corresponds to the sensory evidence and priors the model keeps about the recent sequence. Active Inference describes this in terms of hierarchical temporal models that extend the horizon over which prediction operates. Not every theory of the mismatch negativity takes this form, and echoic memory is traditionally described in information-processing terms without reference to free energy.
