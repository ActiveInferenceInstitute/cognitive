# Lavie Load Theory

## Overview
Lavie's load theory is an account of selective attention that was proposed to resolve the long-running early versus late selection debate (see [[selective_attention]]). It holds that whether irrelevant stimuli are processed depends on the load of the current task. Two mechanisms are distinguished. Perceptual capacity is limited but is allocated automatically, so that processing of task-irrelevant stimuli continues until capacity is used up. Cognitive control, which depends on working memory and executive resources, is needed to keep behaviour aligned with the current goal.

## Core predictions
- **High perceptual load reduces distractor interference.** When the relevant task uses most of perceptual capacity, for example by presenting more items or requiring harder discriminations, there is little capacity left over for distractors, which then interfere less. This was reported by Lavie (1995) using the flanker paradigm, where the response to a target is affected by a distractor letter.
- **High cognitive load increases distractor interference.** When working memory is occupied, for example by a memory set to be maintained, control over priorities weakens and distractors interfere more (Lavie and colleagues, 2004).

The two kinds of load therefore have opposite effects, which is the signature prediction of the theory. Later work extended it to awareness, as in [[inattentional_blindness]], and to applied settings. Reported complications include variations in how load is defined and manipulated, and evidence that distractor salience and other factors also matter. A more general statement of the idea appears under [[load_theory]].

## Relation to Active Inference
Active Inference treats attention as the optimisation of precision, the confidence assigned to prediction errors at different levels and channels (see [[precision_weighting]]). Load effects can be described in this language as competition for finite precision resources, but load theory itself was formulated in capacity terms. Mapping its two load types onto distinct precision parameters is an interpretation and has not been established as a derivation.
