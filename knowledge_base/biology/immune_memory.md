# Immune Memory

## Overview
Immune memory is the ability of the immune system to respond more rapidly and effectively to a pathogen it has met before. It underlies the protection given by vaccination and by recovery from many infections. The classical form is part of adaptive immunity and depends on lymphocytes with antigen-specific receptors.

## Mechanism
After a first infection, B and T cells that recognise the pathogen's antigens proliferate in a clonal expansion. Most effector cells die when the infection is cleared, but a fraction persists as memory cells. In B cells, affinity maturation in germinal centres produces antibodies with improved binding through somatic hypermutation and selection, and long-lived plasma cells can maintain circulating antibody for long periods. Memory T cells include subsets that differ in location and function: central memory cells recirculate through lymphoid tissue, while effector memory cells are found in peripheral tissues (Sallusto et al., 1999). On re-exposure, memory cells are more numerous and respond with lower activation thresholds, so the secondary response is faster and usually stronger than the primary one.

## Innate memory
Innate immune cells lack antigen-specific receptors, but they can show changed responsiveness after an earlier stimulus, called trained immunity. It involves epigenetic and metabolic reprogramming of cells such as monocytes and their progenitors, and it is not antigen-specific in the way adaptive memory is. Plants and invertebrates show forms of immune priming, and some of these cases are debated.

## Relation to Active Inference
The vault's page on the [[free_energy_principle]] mentions the immune system as one of the biological systems that maintain themselves by regulating their state. Some theoretical proposals describe immune responses as a form of inference, with clonal selection resembling Bayesian model selection and memory as updated priors about the pathogen environment. These are conceptual proposals. Immunological explanations rest on cell and molecular biology, and no accepted Active Inference model of immune memory exists.
