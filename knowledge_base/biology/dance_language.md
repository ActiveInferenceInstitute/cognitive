# Dance Language

## Overview
The dance language is the system by which foraging honey bees (*Apis mellifera*) inform nestmates about the location of resources such as nectar, pollen, water or a prospective nest site. Karl von Frisch decoded the system in the first half of the twentieth century and shared the 1973 Nobel Prize in Physiology or Medicine for work on animal behaviour. It is one of the few known cases in which an invertebrate uses a symbolic code in which the form of a movement refers to a place that is not present.

## The code
A successful forager returns to the dark hive and dances on the vertical comb, followed by other bees that attend to it closely.
- **Waggle dance.** For distant sources the bee repeats a figure-of-eight pattern. The straight waggle run carries the information: its angle from the vertical corresponds to the angle between the sun's azimuth and the direction to the source, and its duration increases with distance.
- **Round dance.** For nearby sources, the dance has no clear directional component.
- **Quality.** Dancers tend to continue longer and perform more waggle runs for richer sources, so recruitment is biased towards better patches (Seeley, 1995).

Followers also receive odour cues clinging to the dancer's body, and the interplay of dance and odour information was historically contested. A radar tracking study showed that recruits fly to the location indicated by the dance (Riley et al., 2005), which supports von Frisch's interpretation.

## Collective foraging
No bee surveys the whole landscape. The colony allocates foragers across patches because recruitment depends on the dancers' assessments and on the number of bees that follow each dance. The same machinery is used when a swarm chooses a new home, where scouts compete through dances until support for one site passes a threshold (Seeley, 2010).

## Relation to Active Inference
The link is an analogy and a case study. A dance transmits a compact message that updates a follower's beliefs about where resources lie, which fits generative-model treatments of communication between agents, but no standard Active Inference model of the bee dance has been established.
